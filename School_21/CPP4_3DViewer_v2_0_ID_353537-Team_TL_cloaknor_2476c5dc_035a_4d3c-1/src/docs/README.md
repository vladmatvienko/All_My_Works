# 3DViewer v2.0

Приложение визуализирует каркасные OBJ-модели, поддерживает загрузку вершин и граней, перемещение, поворот и масштабирование модели.

## Архитектура

- `model` — бизнес-логика: сцена, фигура, OBJ-ридер, матрицы трансформаций, фасад, стратегия отрисовки, настройки и GIF-кодер.
- `controller` — тонкий MVC-контроллер, который прокидывает запросы во `Facade`.
- `commands` — команды пользовательских действий.
- `view` — Qt-интерфейс, OpenGL-виджет, сохранение настроек и фоновые операции через `BackgroundWorker`.
- `tests` — unit-тесты загрузчика OBJ, аффинных преобразований, настроек и GIF.

## Паттерны

- MVC — разделение представления, контроллера и модели.
- Facade — `s21::Facade` скрывает загрузку, трансформации и отрисовку.
- Strategy — `SceneDrawerBase` позволяет менять способ отрисовки.
- Command — пользовательские действия оформлены объектами-командами.

## Возможности

- Part 1: загрузка OBJ, аффинные преобразования, каркасная визуализация.
- Part 2: проекция, стиль рёбер и вершин, цвет фона, сохранение настроек через `QSettings`.
- Part 3: экспорт BMP/JPEG и GIF-скринкаст 640x480, 10 fps, 5 секунд.

## Сборка
