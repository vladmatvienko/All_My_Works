# BrickGame v2.0: Tetris + Snake

Проект реализует BrickGame v2.0 на C/C++20 с общим API интерфейсов и игровых библиотек.

## Состав

- `src/brick_game/tetris` — перенесенная библиотека Tetris из BrickGame v1.0 с совместимым API и префиксными функциями для одновременной линковки нескольких игр.
- `src/brick_game/snake` — библиотека Snake на C++20 в namespace `s21`, реализованная по MVC: модель содержит игровую механику и конечный автомат, контроллер является тонким фасадом, UI не содержит бизнес-логики.
- `src/gui/cli` — консольный интерфейс ncurses, поддерживает Tetris и Snake.
- `src/gui/desktop` — десктопный интерфейс Qt Widgets, поддерживает Tetris и Snake.
- `src/tests` — unit-тесты для библиотек Tetris и Snake.

## Сборка

```sh
cd src
make all
```

Если Qt Widgets не установлен, цель `desktop` будет пропущена без падения сборки. Консольная версия собирается в `build/brick_game_cli`.

## Запуск

```sh
./build/brick_game_cli
```

Управление: `1` — Tetris, `2` — Snake, `S/Enter` — старт, `P` — пауза, стрелки — движение/повороты, `Space` — действие/ускорение, `Q/Esc` — выход.

## Тесты

```sh
make test
```

При наличии системного GTest используется он. В окружениях без GTest подключается минимальный совместимый fallback-заголовок для локальной проверки.
